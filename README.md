### ⭐ Featured projects

| Project | What it is |
| --- | --- |
| [android-clone-detection](https://github.com/eshginfarzali/android-clone-detection) | Catches Android app cloners by comparing libc and raw-syscall answers from the kernel; article + MIT library, published on npm as [`react-native-clone-guard`](https://www.npmjs.com/package/react-native-clone-guard). |
| [nestjs-inventory-erp-api](https://github.com/eshginfarzali/nestjs-inventory-erp-api) | Inventory and production ERP API: NestJS, PostgreSQL + Prisma, JWT refresh rotation, RBAC, a transactional stock ledger that never goes negative, BullMQ low-stock alerts and Testcontainers e2e tests. |
| [Realtime Tic-Tac-Toe](https://github.com/eshginfarzali/realtime-tictactoe-turborepo) | Turborepo with a NestJS game server (Socket.IO + GraphQL), a Next.js + PixiJS client and shared TypeScript game rules. |
| [express-webhook-service](https://github.com/eshginfarzali/express-webhook-service) | Express 5 + TypeScript webhook receiver: HMAC signatures with a replay window, idempotent deliveries, retries with exponential backoff, a dead-letter queue and replay. |
| [python-smart-scraper](https://github.com/eshginfarzali/python-smart-scraper) | Python 3.12 + FastAPI scraping service with an async job queue; respects robots.txt, per-host rate limits and Retry-After by design. |
| [CleanCraft](https://github.com/eshginfarzali/cleancraft_desktop_app) | Tauri + Rust desktop app that removes old cache and temp files from an allow-listed set of folders, with release builds for macOS, Windows and Linux. |
| [movie-app-expo](https://github.com/eshginfarzali/movie-app-expo) | Expo Router movie browser on the TMDB API with a typed service layer and TanStack Query caching. |
